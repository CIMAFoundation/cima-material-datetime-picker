# Theming

With M3, the component uses the `--mat-sys-*` tokens generated by the application's Material theme. For an M2 theme, add the bridge after the Material theme:

```scss
@use '@angular/material' as mat;
@use '@cima-foundation/material-datetime-picker/theming' as cima;

// $theme is the application's M2 theme.
.my-theme {
  @include mat.all-component-themes($theme);
  @include cima.m2-theme($theme);
}
```

The theme class must also be available on the CDK overlay container when the picker is displayed in a popup.

## Material 3 setup

For an application using the current Material theme mixin:

```scss
@use '@angular/material' as mat;

html {
  @include mat.theme((
    color: mat.$violet-palette,
    typography: Roboto,
    density: 0,
  ));
}
```

The timepicker reads the generated system tokens. Color roles follow the reference Material timepicker: surface-container-highest for the dial and unselected fields, primary-container for selected fields, primary for the hand, and tertiary-container for the selected AM/PM period.

## Material 2 setup

Define an M2 theme before using the bridge shown above:

```scss
$theme: mat.m2-define-light-theme((
  color: (
    primary: mat.m2-define-palette(mat.$m2-indigo-palette),
    accent: mat.m2-define-palette(mat.$m2-purple-palette),
  ),
  typography: mat.m2-define-typography-config(),
  density: 0,
));
```

The demo includes M2 styles only for the Material components it renders, keeping the full component catalog out of its global CSS. Applications can use `all-component-themes` as above or include the individual component theme mixins they need.

The bridge maps the M2 theme to system tokens and provides timepicker-specific typography, backgrounds, and corner radii. It does not add support for older Angular versions.

## CSS customization

| Variable | Purpose |
| --- | --- |
| `--cima-time-padding-inline` | Horizontal padding within time-selection content; defaults to 24px |
| `--cima-time-field-radius` | Numeric field and AM/PM group corner radius; 8px by default, 4px through the M2 bridge |
| `--cima-time-display-font` | Font shorthand for numeric displays in both views and their separator |
| `--cima-time-heading-font` | Heading font shorthand |
| `--cima-time-period-font` | AM/PM button font shorthand |
| `--cima-time-face-background` | Dial background override |
| `--cima-time-field-background` | Unselected numeric field background override |

The public time popup and demo cards use `--cima-time-panel-radius` and `--cima-time-panel-shadow` for their outer surface. The content component does not create those surfaces itself.

The datetime demo overrides only the content's horizontal padding because Material actions and the scroll container already provide outer spacing. Avoid stacking another fixed padding on top of these layers.

## Overlay themes

A theme class on the application root does not automatically reach the CDK overlay container. Apply the relevant class to the container returned by `OverlayContainer.getContainerElement()` as well. The demo uses this public API to switch M2/M3 styles for popups.

Dark-theme and RTL behavior have not yet received a complete verification pass. The hand animation respects `prefers-reduced-motion`.
